# ChatGPT Native Longshot

点击单条 ChatGPT 回答下方的「复制长图」线性图标，将浏览器实际渲染的回答保存为 PNG，并尝试直接写入系统剪贴板。保留页面当前字体、换行、公式、表格、代码块、图片与主题。完全在本地处理。

## 安装

从 GitHub 获取源码后，先在项目目录构建扩展：

```sh
git clone https://github.com/Kyrieeeeeee/chatgpt-native-longshot.git
cd chatgpt-native-longshot
npm ci
npm run build
```

1. 打开 `chrome://extensions`，启用右上角「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择本项目的 **`dist` 文件夹**。
3. 刷新已经打开的 ChatGPT 标签页。
4. 等回答生成结束，点击回答操作区的「复制长图」图标。
5. 完成后直接粘贴到 Obsidian、微信或其他支持图片的应用。

点击后会立即显示转圈提示，依次显示截图、拼接百分比、复制到剪贴板；完成、失败或取消后给出结果。提示在捕获过程中保持可见，不会出现在导出的图片中。

截图、复制及准备预览期间，其他回答的截图按钮会暂时禁用，结束后恢复。多图预览会在当前图片旁显示带编号的复制结果；一次仅复制一张，避免剪贴板内容被并发操作覆盖。

要求桌面 Chrome 118 或更新版本。支持 `https://chatgpt.com/` 和 `https://chat.openai.com/`。截图期间保持该标签页在前台，不要滚动、改窗口大小或缩放；按 **Esc** 可取消。进入「正在复制到剪贴板」阶段后，系统写入无法取消。Chrome 会短暂显示「正在调试此浏览器」提示条，完成后自动释放调试会话。

复制失败时，消息会显示「图片生成成功，但复制失败」。点击「打开预览 / 保存 PNG」，可再次点击复制图片或保存 PNG。超长内容分成多张 PNG，逐张复制或保存，不会悄悄缩小图片。预览只保留于内存，关闭或清除即释放；刷新预览需要重新截图。

## 设置面板、回复宽度与时间线

点击 Chrome 工具栏的本扩展图标打开 Voyager 风格的设置面板，支持明暗主题、提示词与公式复制开关、提示词备份导入导出，以及回复宽度与时间线。使用现有 storage 权限，不新增站点权限或运行时网络请求。

回复宽度提供 50–100% 滑杆和紧凑 / 宽屏 / 铺满预设，可一键恢复原始宽度；提问与助手回复的内容列同步调整，已发送消息随新宽度靠右对齐，保留气泡样式；输入框和草稿保持原样。时间线显示当前已加载的问题，支持悬停预览、点击定位、上一条 / 下一条和滚动高亮，随着页面加载历史或新消息自动更新。少于两条问题时不显示；未加载的历史需要先让 ChatGPT 加载。

时间线支持 Voyager 风格圆点 / 标尺 / 紧凑刻度三种样式，新设置默认紧凑。标尺和紧凑刻度居中分布，最大10px间距、240px总长度；紧凑模式悬停150ms打开320px问题列表，不抢走编辑焦点，移开220ms后收起（固定时保留）。支持问题与回复搜索、对话内收藏、平滑 / 立即跳转；右击或长按550ms收藏节点，移动超过6px取消。拖动顶部把手调整左右边和高度，双击或设置面板重置；位置和收藏刷新后保留。点击计数也可打开列表，Esc关闭；聚焦节点后可用 ↑ / ↓、Home / End导航。点击时重新测量可见消息容器，兼容隐藏标题、嵌套与整页滚动；长回复中的当前高亮不会提前切到下一题，连续平滑跳转保留目标。仅索引当前已加载的历史；无消息时仍可通过设置面板打开空列表。

宽度和时间线默认关闭，保持当前页面布局，避免和已有导航扩展叠放。面板更改立即应用到当前 ChatGPT 标签页；其他已打开的标签页在下次刷新时读取已保存设置。提示词内容仍跨标签页更新。

## Gemini 提示词

同一扩展也支持 `https://gemini.google.com/`：悬浮球管理、常用排序、`/关键词` 搜索、名称胶囊与发送前还原正文，和 ChatGPT 共用提示词库，不需要重新导入。支持 Gemini 的 rich-textarea / Quill 输入框，中文输入法组词及停止回答按钮不会触发正文展开。更新扩展后刷新 Gemini 页面生效。

Gemini 只加载提示词入口；长图、公式复制、回复宽度、时间线和思考强度快捷键仍用于 ChatGPT。Gemini 站点匹配是本次新增的内容脚本范围，没有后台上传提示词或读取账号接口。

## 提示词管理与公式复制

蓝色悬浮球打开提示词管理，可拖动贴边并记住位置。面板按照 Voyager 1.8.3 的紧凑模式整理为 440px 单列：标题点击直接插入，悬停 250ms 预览完整正文，右侧显示标签和展开、编辑、删除按钮。支持列表/卡片切换、主题切换、固定面板和拖动标题栏；低频导入导出与草稿保存位于底部「设置」。

列表中的 ☆ 可直接设为常用置顶，也可在展开正文后收藏。管理列表和 `/` 候选均按星标优先、使用次数、最近使用时间排序；只有成功插入才计次，原有条目存储顺序保留。收藏和使用记录随 JSON 导出/导入保留，编辑正文不清除记录。固定面板时可继续在 ChatGPT 中编辑草稿，插入使用最新光标位置。原有提示词数据直接保留。

在 ChatGPT 输入框输入 `/` 或 `/关键词`，用 ↑↓ 选择，Enter / Tab 或点击插入名称胶囊，Esc 关闭。仅替换光标前的 `/关键词`，保留其他草稿；选择操作不会发送消息，可用系统撤销恢复。胶囊采用 Voyager 的包裹图标，悬停预览完整正文，双击可展开编辑；明确按 Enter 或点击发送时先还原正文，再交给页面发送。复制胶囊也得到完整正文，支持多枚胶囊、整枚删除与撤销；同一标签页和对话的胶囊草稿可随页面草稿刷新恢复。候选打开时仅隐藏 ChatGPT 原生输入框命令浮层，避免双菜单重叠；按 Alt+/ 切回原生功能。候选采用 Voyager 的 380px 紧凑列表：标题在左，描边标签在右，无标题栏和底栏，悬停显示正文。

面板底部「设置」提供保存当前草稿、导出 JSON、导入 JSON 和重置悬浮球位置。导入追加合并，完全重复的条目跳过，格式错误会整份拒绝，不覆盖原库。接受提示词数组、`{ "prompts": [...] }` 或 Voyager 的 `{ "format": "gemini-voyager.prompts.v1", "items": [...] }`，字段支持 `name` / `title`、`content` / `text` 和数组/逗号分隔的 `tags`。已核对 Voyager 1.8.3 导出的提示词备份结构。

悬停渲染好的公式时，公式区域出现细框和浅底色，直接点击该区域复制，无额外复制按钮。不添加内边距，不改变公式尺寸或换行。与 Voyager 默认 LaTeX 格式一致：行内为 `$...$`，块级为 `$$...$$`。支持带 TeX annotation 的 KaTeX 及带源属性的 MathJax；没有源码的公式不会猜测或误复制渲染文字。编辑框内公式、文本选区拖动、截图期间不触发复制。

功能行为参考 [Voyager 提示词库](https://voyager.nagi.fun/en/guide/prompts) 与 [公式复制](https://voyager.nagi.fun/en/guide/formula-copy)，代码为本扩展独立实现。

## 思考强度快捷键

在 ChatGPT 页面**Fn + →** 向下一档循环切换，**Fn + ←** 向上一档循环切换当前模型支持的思考强度。输入框内也可使用，保留草稿；中文输入法正在组词时不响应。支持页面上的中英文新旧菜单选项以及新版思考强度滑块，跳过不可用档位，切换后显示结果并恢复输入框焦点。请先选择支持调整思考强度的模型；不会自动替你切换模型或发送草稿。截图期间请等截图完成后再切换。

连续短按左右键会逐次执行，不再因为上一次正在切换而丢掉按键；同一轮滑块切换复用菜单。切换期间继续输入、点击别处、换对话或开始截图，会停止尚未完成的步骤并让出焦点。延迟与兼容性测试见 [快捷键审查记录](docs/THINKING_REVIEW.md)。

更新后在 `chrome://extensions` 中重新加载本扩展，再刷新 ChatGPT 页面。Fn + → / Fn + ← 是扩展内置组合键，无需在 Chrome 设置。macOS 会将它们转换为 End / Home，因此独立 End / Home 键也会触发对应方向的切换，并替代该键在 ChatGPT 页内的原有跳转行为。另保留 **⌥⇧Y（Alt+Shift+Y）** 作为备用快捷键，可在 `chrome://extensions/shortcuts` 修改。

0.2.5 复用提示词胶囊节点与 textarea 测量镜像，合并快速设置操作中尚未处理的快照，并在预览中途清除时立即释放后台缓冲。性能证据与保留问题见 [性能审查记录](docs/PERFORMANCE_REVIEW.md)。

- `npm run test:productivity`：隔离浏览器验证提示词保存、搜索插入、草稿与撤销、实际 LaTeX 剪贴板和窄屏面板。
- `npm run test:tokens
npm run test:gemini`：隔离浏览器验证胶囊名称/预览、多胶囊、Enter/按钮发送正文、复制、删除撤销、刷新/编辑器重建、禁用恢复、textarea，以及公式框选范围直接复制与几何不变。

## 权限与隐私

| 项目 | 用途 |
| --- | --- |
| `debugger` | 调用 Chrome 原生 `Page.captureScreenshot`；按需连接当前点击回答所在标签页，完成、失败或取消后断开。Chrome 会展示敏感调试权限提示。该 API 本身权限较宽，应用代码严格校验来源，只接受两个 ChatGPT 域的顶层页面请求。 |
| `clipboardWrite` | 截图完成后异步写入真正的 `image/png`，避免用户激活过期。只有写入 Promise 成功才提示复制成功。 |
| `content_scripts.matches` | 仅在两个 ChatGPT 官方网页域自动注入回答按钮。没有 `<all_urls>`、远程脚本、遥测或上传接口。 |

`storage` 用于在本机 Chrome 扩展存储中保存提示词；跨标签页更新，不进行云同步。没有申请 `tabs`、`downloads`、`activeTab` 或 `offscreen`。预览通过本地 Blob 下载，不需要下载权限；正文和截图不写入浏览器持久存储。没有运行时网络请求；开发安装依赖、测试夹具的本地图片请求不属于扩展运行时数据上传。

## 已知限制

- 站点 DOM 没有官方稳定接口。已覆盖传统角色元素和新版助手语义标题 / turn 结构；角色 data 属性、语义容器、操作区回退可降低变化风险，但不能保证未来任何版本都兼容。
- 不处理正在流式生成的回答。字体、图片须成功加载，持续 DOM 或几何变化会停止捕获并说明原因。视频、GIF、Canvas 内部动态像素无法可靠检测，请先暂停；分片不保证它们来自同一瞬间。
- 内部横向或纵向滚动的代码块、宽表格按当前可见部分截图，完成消息会明确提示。不会拉宽或展开改变原始布局。
- 折叠部分、尚未创建的虚拟化内容不属于当前可见 DOM，无法承诺包含。已存在图片会临时请求 eager 加载，完成后恢复 `loading` 属性。
- 原样模式不会修改视口、页面缩放、正文宽度或重新渲染 Markdown。调试提示条若触发正文宽高变化，会拒绝导出。复杂 sticky、跨域 iframe、视频等需真实页面单独核验。
- 优先生成一张 PNG：高度最多 65535 物理像素，单张最多 1.28 亿像素（实际高度还取决于宽度，例如宽 2153 时最多 59451 高）。总像素最多 1.92 亿，最多 16 张，PNG 合计最多 64 MiB，任务最多 120 秒。超过单张预算才分段，不自动压缩文字。大图会增加内存消耗，设备内存不足时会明确报错。
- 自定义导出宽度模式仅预留内部接口，未开放 UI。
- 系统剪贴板容量、Chrome/系统策略或页面焦点可能使复制失败；可使用预览与保存路径。

## 排错

- **没有按钮**：确认加载的是 `dist/`，允许在 ChatGPT 运行扩展，并刷新网页。若网页更新导致角色元素变化，检查 `src/adapter.ts`。
- **无法启动调试**：关闭该标签页 DevTools，检查是否有其他截图/调试扩展连接，或企业策略禁止截图。不要关闭整个浏览器。
- **布局改变 / 可见区域空缺**：保持桌面窗口足够宽，关闭覆盖正文的对话框，展开目标内容后重新截图。
- **图片加载失败 / 超时**：先在网页中确认图片可见，再重试。
- **复制失败**：点击反馈中的预览，保持预览页焦点，再点「复制图片」；仍失败可保存 PNG。
- **取消**：截图中按 Esc，等待提示「已取消」。滚动位置和临时样式会恢复。若手动终止了扩展或刷新页面，Chrome 本身会销毁旧页面状态；可以刷新恢复按钮。

## 性能审查与回归

2026-10-17 已对截图、提示词、时间线、后台和构建进行性能审查与局部优化。完整架构、前后实测、资源限制与未验证边界见 [性能优化报告](docs/PERFORMANCE_REVIEW.md)。

运行 `npm run test:performance` 验证 1000 条提示词、500 轮流式对话、候选高亮、CSSOM 样式变化检查、即时稳定签名复核与资源恢复；毫秒测量仅作对比，回归断言针对节点/属性操作数量。生产构建压缩，`npm run dev` 保持可读输出。
