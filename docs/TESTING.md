## 测试如何证明扩展输出

浏览器实际加载测试版 MV3 扩展，点击注入的按钮。成功单图来自真实 Clipboard API 读取的 `image/png`；超长分段来自扩展预览页持有的 PNG Blob。不是以 Playwright 的截图充当扩展输出，也没有调用模拟截图引擎。

参考图在另一个相同浏览器标签页、同样 DOM、同样窗口/缩放/DPI、同样 Chrome 调试提示条条件下，用独立 CDP 原生截图采集。始终维持真实视口；按 256 物理像素行分带取样并等待几何与连续原生位图稳定，使用 Node PNG 工具组装参考。参考代码不使用扩展几何或拼接模块，与扩展的视口分片边界不同。

逐像素比较 RGB，要求差异像素数 **0**，平均差异 **0**，最大差异 **0**；未使用模糊相似度、抗锯齿容差或放宽断言。每个视觉场景输出 `*-output.png`、`*-reference.png`、`*-diff.png` 和数值统计。

测试版独立 manifest 只匹配 `127.0.0.1:8799`，额外持有 `clipboardRead` 来验证实际写入。生产版只匹配两个 ChatGPT 域，只持有 `debugger`、`clipboardWrite`，没有剪贴板读取权限。

复制拒绝测试是测试构建内的显式 `NotAllowedError` 故障注入，用于核验错误文案、预览复制和保存，不冒充真实企业策略拒绝。动态内容与窗口变化测试在**真实原生截图已返回、尚未交给 content script**的时刻同步注入变化，以避免靠不可靠 sleep 猜测触发时间。正向截图、拼接与剪贴板写入均为真实 API。

## 已定位并修复的问题

1. 未申请 tabs/host_permissions 时，`tabs.get()` 的 URL 属性缺失。改为每次验证消息发送者 URL，另用无权限的 active 标志判断目标标签页状态。
2. Chrome 调试提示条异步出现与消失。捕获前等待真实视口稳定，清理后等待其消失再恢复 scrollTop，避免底部位置二次夹紧。
3. 极短清理窗口中的取消。截图协调返回后再次检查取消信号，避免已经取消仍覆盖剪贴板。
4. 调试器已断开时，释放操作保持幂等，其他释放失败仍明确报告。
5. 参考采集的时序和坐标。Playwright 模拟视口可与扩展捕获表面尺寸不同；默认截图在浏览器缩放下还可能选择 CSS 尺度。一次超视口截图在此环境观察到首屏重复。因此改为真实窗口、原生无 clip 可视截图、相同提示条及合成器稳定检查。没有修改参考文字、目标 CSS 或容差来凑通过。

## 真实站点手动验收

1. 在 `chrome://extensions` 加载 `dist/`，刷新已登录的 ChatGPT。
2. 对一条包含中文、公式、表格、代码与图片的已完成回答点击「复制长图」。粘贴到 Obsidian 或微信，核对首末行、换行位置、表格/公式和接缝。
3. 在多轮对话分别点击不同回答，确认每张只包含被点击的那条；再切换对话，检查按钮仍只出现一次。
4. 分别在浅色、深色以及常用缩放下检查；超过单图上限时打开预览逐张保存。
5. 长回答捕获中按 Esc，确认原滚动位置恢复、剪贴板未被替换、调试提示条消失。
6. 若自动复制失败，使用反馈中的「打开预览 / 保存 PNG」，保持预览焦点后点击复制，或保存 PNG。

发现站点适配问题时，优先排查 `src/adapter.ts` 的角色元素与操作区关联；不要通过更改正文宽度或重新渲染 Markdown 规避问题。
